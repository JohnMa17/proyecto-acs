# Síntesis Interactiva: Administración de la Configuración del Software (ACS)

Resumen técnico e interactivo de la Sección 22.3 (2.3) de Roger S. Pressman, publicado mediante GitHub Pages.

## Integrantes
* John Manuel Guerrero Vilorio (Rama: rama-estudiante-1)
* Duran  (Rama: rama-estudiante-2)
* Ezequiel Peguero Bautista (Rama: rama-estudiante-3)

## Objetivo de la Actividad
Analizar y sintetizar la Sección de ACS demostrando la aplicación práctica del control de versiones y trabajo colaborativo no lineal con Git y GitHub.

## Tecnologías utilizadas
* HTML5
* CSS3 (variables CSS, Grid y Flexbox)
* JavaScript (vanilla, sin librerías)
* Git y GitHub (control de versiones, ramas y Pull Requests)
* GitHub Pages (publicación)

## Estructura del Repositorio
